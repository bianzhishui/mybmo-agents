# 出图提示词（成员3 产出 → 外部出图 → 成员4 打包）

> 本文件由成员3 写；每张图**一个编号块**，编号即后续文件名，**不得跳号、不得重号**。
> 连接器没有文生图能力，出图在外部完成；出好的图必须按 `img-00N.<ext>` 命名放进 `04-assets/`。
>
> **尺寸是精确宽高白名单、方向固定**（不是宽高比、不是最小尺寸）：商品推广只有 `370×245 / 1140×640 / 750×1000`，
> 自定义直播推广只有 `1140×640`。375×248、960×540（同为 16:9）、1000×750、640×1140 实测全部被 901217 拒。
> `pictures` 张数上限 18（服务端拦，schema 无 maxItems）。
>
> **内容红线（AI 水印 / 使用前后对比 / 绝对化用语）是我方审计口径，不是平台拒审条件**——
> 平台不会因此拒单，但审计官会打回，`scripts/assets_pack.py` 会要求逐张自查声明。
>
> 占位符统一用 `PENDING:<img-00N>.<ext>`（如 `PENDING:img-001.png`），⑤ 计划草案与 ⑥ payload 必须引用同一个追溯键。

## 编号块模板（逐张复制）

```markdown
## img-001
- 用途：<material.pictures[0] / 对应 title#1>
- 尺寸：<精确宽高，必须是 370×245 / 1140×640 / 750×1000 之一（商品推广）；方向固定，禁止按宽高比或最小边推导>
- 画面要素：<产品形态、构图、背景、光线、产品占画面比例>
- 是否允许文字入图：<是/否；若"是"必须给出确切文案>
- 负面词：<如 no text, no watermark, no logo, no hands, no extra props>
- 合规：不得出现"最/第一/根治/百分百/永久"等绝对化文字；不得承诺疗效
- 完整提示词：<可直接粘贴给文生图工具的一整段>
```
